# RT01-T06 — FAPESP, FAPESC e Web

**Objetivo:** aplicar o contrato validado em T05 às demais origens de
oportunidade, sem unificar seus adapters.

## Entrega

- dual-write em FAPESP, FAPESC e Web promovida;
- HTML sem página tratado explicitamente;
- evidence package Web preservado;
- uma fixture por origem.

## Validação

- equivalência por origem;
- testes direcionados dos adapters/produtores alterados;
- promoção Web continua exigindo gate humano.

## Pare

Pare se uma origem precisar de regra específica de produto ou se a mudança
criar branch por fonte à direita do Documento Canônico.
