# Registros históricos

Este diretório preserva decisões, pesquisas, auditorias, specs e arquiteturas
que não governam o sistema atual. A linguagem no presente e os paths originais
devem ser lidos no contexto da data de cada documento.

Para o estado vigente, comece pelo [índice da documentação](../README.md), pela
[`architecture.md`](../architecture.md) e pelas specs em [`docs/specs/`](../specs/).

Mover um arquivo para este diretório não refuta nem apaga seu conteúdo; apenas
retira sua autoridade sobre o presente.
